# Pantógrafo nuevo

Conjunto de tres máquinas que trabajan conectadas entre sí:

- **Mesa de carga:** Auto Feeder, modelo **KA-2710**.
- **Mesa de corte:** Engraving Machine, modelo **KN-3710H**.
- **Mesa de salida:** Auto Stacker, modelo **KA-9710**.

## Fabricante

Guangzhou KDT Machinery Co., Ltd.

## Datos identificados

- Mesas de carga y salida: panel de 3050 mm de largo, 2100 mm de ancho y espesor de 10–25 mm.
- Mesa de corte: potencia total indicada de 33,05 kW, alimentación trifásica 380 V / 50 Hz y peso indicado de 5000 kg.
- Fecha visible en las placas de las mesas de carga y salida: 2020/06/09.
- Fecha visible en la placa de la mesa de corte: 2019/04/27.

## Organización

- `01_Identificacion`: fotos de las placas y datos de identificación.
- `02_Mesas`: documentación específica de cada mesa.
- `03_Documentacion`: manuales, planos, conexiones y demás archivos que se incorporen.

- `03_Documentacion/Requerimientos_instalacion`: hoja de requisitos entregada por el vendedor antes de la instalación.

Los datos quedan sujetos a confirmación mediante manuales o nuevas fotografías de las placas y conexiones.
