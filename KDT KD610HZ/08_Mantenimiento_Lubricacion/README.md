# Mantenimiento y lubricación

## Manual ULTRAFLEX de M. Caseros

El archivo `Generico_M_Caseros/Manual_lubricacion_ULTRAFLEX_generico.pdf` se conserva como referencia de mantenimiento.

### Información útil que aporta

- **Bomba de lubricación:** grasa fluida GL00 o GL000; recargar hasta 3/4 cuando el nivel esté por debajo de 1/4 y accionar la palanca 3 a 5 veces antes del trabajo diario.
- **Cabezal de agujereado:** grasa Klüber Isoflex Topas L32; agregar 5 cc cada 40 horas de uso.
- **Alemite manual:** grasa fluida GL00 o GL000.
- **Bomba de aceite semiautomática:** aceite AW46 / VG46; llenar hasta 3/4 cuando el nivel esté por debajo de 1/4.
- **Guías lineales:** grasa fluida GL00 o GL000.
- **FRL neumática:** aceite SAE 20.

### Estado de aplicación

El documento se presenta como **genérico** y al final indica verificar los modelos 2309, 610 y 612. Por eso no se debe tomar como confirmación definitiva de cantidades, puntos de engrase o intervalos para la KDT KD-610HZ de número de serie 6610220700121. Se puede usar como guía hasta contrastarlo con el manual específico, las placas de la máquina y el plan de mantenimiento del fabricante.
