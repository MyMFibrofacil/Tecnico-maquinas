# Manuales de componentes

## CUH SDVC22-S

El controlador está identificado en las fotos de los bowls. Se guardó el catálogo técnico del fabricante CUH, que incluye el modelo SDVC22-S y sus características generales.

Fuente oficial: https://www.cuh-controller.com/imglibs/files/2e3de8ec-98dc-4c77-8252-ee8b6097b0ff.pdf

## OPTEX D3RF-TN

El modelo aparece legible en los amplificadores de fibra. OPTEX identifica el D3RF-TN como amplificador de fibra óptica independiente, de una salida, tipo NPN. La serie está discontinuada; OPTEX indica la familia D4RF como alternativa, pero no debe comprarse como reemplazo directo sin validar conexión, lógica y dimensiones.

Fuentes oficiales:

- https://www.optex-fa.com/global/products/fiber-optic-sensors/fiber-optic-sensors/d3rf/d3rf-tn/
- https://www.optex-fa.com/global/products/fiber-optic-sensors/fiber-optic-sensors/d3rf/specification/
- https://www.optex-fa.com/products/discontinue/pdf/Notice-End_of_Sales_D3RF.pdf
- Catálogo de la serie: https://www.optex-fa.com/products/discontinue/pdf/nf-2501/nf-thread_catalog.pdf
